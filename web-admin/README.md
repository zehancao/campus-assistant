# Web 管理后台 — 智能校园助手

## 技术栈
- Vue 3 + TypeScript
- Vite
- Naive UI / Arco Design（组件库）
- ECharts 5（数据可视化）
- Tiptap（富文本编辑器）
- Axios（HTTP 请求）
- Pinia（状态管理）
- Vue Router（路由）

## 注意事项
- 所有接口调用统一走 `api/request.ts` 里封装的 Axios 实例
- token 过期（401）自动跳转登录页
- 大屏布局用 `vw/vh` 单位，保证 1920×1080 全屏自适应
- 富文本内容存储 HTML 格式，展示时用 `v-html`（注意 XSS 过滤）
- 和组员D 保持沟通，接口返回格式有疑问随时群里问
